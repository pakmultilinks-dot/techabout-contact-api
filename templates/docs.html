Contact Inquiry API

TechAbout. Receives contact-form inquiries and stores them in SQLite.

Submit an inquiry

POST /api/inquiries with a JSON body:

{
  "name": "Ahmed Khan",
  "email": "ahmed@example.com",
  "message": "I would like a quote for a company website."
}

Validation: name required (max 100 chars), email required and must be a valid address, message required (max 2000 chars). Returns 201 with the stored inquiry, or 400 with an errors list.

List inquiries

GET /api/inquiries returns all inquiries, newest last:

{
  "count": 2,
  "inquiries": [
    {"id": 1, "name": "Ahmed Khan", "email": "ahmed@example.com",
     "message": "...", "created_at": "2026-10-05T10:00:00"},
    {"id": 2, "...": "..."}
  ]
}

Optional filters:

  • GET /api/inquiries?date=2026-10-05 : one day
  • GET /api/inquiries?from=2026-10-01&to=2026-10-05 : date range

Bad date formats return 400 with an errors list.

Fetch one inquiry

GET /api/inquiries/1 returns the inquiry, or 404 if it does not exist.

Health check

GET /api/health returns {"status": "ok"}.
